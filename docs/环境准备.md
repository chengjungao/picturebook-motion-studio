# 环境准备

要装的东西只有三样：**Python**、**ffmpeg**、**ComfyUI ＋ 三个模型文件**。
下面按「最容易装错」的顺序排。

装完先跑一次自检，它会告诉你还差什么：

```
python app.py --check
```

Windows 上双击 **`启动-自检.bat`** 更省事，它顺带把时间轴也给你算出来。

---

## 1. Python

**3.8 以上**，装了就行。本项目只用标准库，**不要 `pip install` 任何东西**。

* Windows：到 python.org 下载安装包，装的时候**务必勾上 `Add python.exe to PATH`**
* macOS：`brew install python`
* Linux：`sudo apt install python3`

---

## 2. ffmpeg

**合成这一步全靠它**，没有它一条片子也出不来。

| 系统 | 怎么做 |
|---|---|
| Windows | `winget install Gyan.FFmpeg`，或到 ffmpeg.org 下载压缩包，把里面的 `bin` 目录加进 PATH |
| macOS | `brew install ffmpeg` |
| Linux | `sudo apt install ffmpeg` |

装完验证：

```
ffmpeg -version
ffprobe -version
```

**两个都要有。** `ffprobe` 跟 `ffmpeg` 是一起发的，如果你只有一个，
说明 PATH 里指到了别处，自检会提示。

> 不想动 PATH 也行：在 `config.json` 的 `ffmpeg` 一节直接写绝对路径。
> ```json
> "ffmpeg": { "ffmpeg": "D:/tools/ffmpeg/bin/ffmpeg.exe", "ffprobe": "D:/tools/ffmpeg/bin/ffprobe.exe" }
> ```

---

## 3. ComfyUI

Windows 上用**便携版**最省事：到 ComfyUI 的 releases 页下 `ComfyUI_windows_portable`，
解压到一个**路径里没有空格和中文**的地方，双击里面的 `run_nvidia_gpu.bat`。

启动之后浏览器会打开 ComfyUI 的界面，那就是好了。

> **本项目不需要在 ComfyUI 界面里做任何操作。** 它通过 HTTP API 提交任务，
> 你只要保证那个黑窗口开着。默认地址 `http://127.0.0.1:8188`，
> 装在别的机器上就在 `config.json` 里改 `comfy_url`。

macOS / Linux 装 ComfyUI 见官方仓库的说明，装完用
`python main.py` 启动（**不要加 `--listen`**，除非你清楚在做什么）。

### ComfyUI 版本要求

自检会检查这几个节点在不在，缺任何一个都说明版本太旧，升级 ComfyUI 即可：

```
UNETLoader  CLIPLoader  VAELoader  CLIPTextEncode  LoadImage
ModelSamplingSD3  Wan22ImageToVideoLatent  KSampler  VAEDecode
CreateVideo  SaveVideo
```

`CreateVideo` 与 `SaveVideo` 是比较新才有的。老版本只有 `VHS_VideoCombine`
（VideoHelperSuite 插件），本项目没有适配它。

## 4. 三个模型文件

**放在 ComfyUI 的 `models` 目录下**，文件夹名不能错：

| 文件 | 放哪 | 大概多大 |
|---|---|---|
| `wan2.2_ti2v_5B_fp16.safetensors` | `ComfyUI/models/diffusion_models/` | 约 10 GB |
| `umt5_xxl_fp8_e4m3fn_scaled.safetensors` | `ComfyUI/models/text_encoders/` | 约 6.7 GB |
| `wan2.2_vae.safetensors` | `ComfyUI/models/vae/` | 约 0.3 GB |

合计约 **17 GB**。下载渠道以官方发布为准（Hugging Face 上的 Comfy-Org 仓库、
或国内的 ModelScope 镜像）。

> ⚠️ **别下那个「FastWan / 蒸馏」的合并版权重。** 名字里带
> `FastWanFullAttn` 的那种只能在 `cfg = 1.0` 下跑，而 `cfg = 1.0` 时
> **负面提示词完全不起作用**，实测它会在 1 秒内把整张页图重绘掉，
> 跟绘本已经不是一张画了。踩过这个坑，见 [常见问题.md](常见问题.md)。

放好之后**重启 ComfyUI**，再跑一次自检，三个文件名应该都是绿色的。

> 文件放对了但自检说「扩散模型里没有 xxx」？说明 ComfyUI 没重新扫过目录，
> 重启它。还不行就是文件名拼错了 —— 自检会把**实际可选的名字**列出来，
> 照着改 `config.json` 就行。

## 5. 想一键生成旁白的话（可选）

本项目不内置语音合成，旁白你自己给。想全本地跑，可以接
**Kokoro-82M 的中文版**（纯 CPU，不占显存）：

1. 单独建一个 Python 环境（**别装进 ComfyUI 那个**）：
   ```
   python -m venv D:\Works\envs\pbtts
   D:\Works\envs\pbtts\Scripts\pip install kokoro soundfile "misaki[zh]" torch
   ```
2. 把模型下到本地，比如 `D:\Works\models\Kokoro-82M-v1.1-zh`，里面有
   `config.json`、`kokoro-v1_1-zh.pth`、`voices/zf_001.pt`
3. 在 `config.json` 里填上：
   ```json
   "tts": {
     "engine": "kokoro",
     "kokoro_python": "D:/Works/envs/pbtts/Scripts/python.exe",
     "kokoro_model_dir": "D:/Works/models/Kokoro-82M-v1.1-zh",
     "voice": "zf_001",
     "speed": 0.9
   }
   ```

重开界面，「配旁白」那一步会多出一个**「用本机 Kokoro 一键生成」**按钮。

> ⚠️ Windows 上 `hf_hub_download` 有软链问题，会把 `config.json` 下成空文件，
> 报 `JSONDecodeError`。所以必须**下到本地、用显式路径**，不要让它在运行时去拉。
> 本项目的调用方式已经绕开了这个问题。
