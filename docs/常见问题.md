# 常见问题

下面每一条都是**真踩过的**，带实测数字。按「症状」找。

---

## 画面：动了，但动的不是我的画

### 出了片段，可画面像被重画了一遍

两种情况，先看是哪一种：

**① 用了「FastWan / 蒸馏」的合并版权重。**
文件名里带 `FastWanFullAttn` 的那种，只能在 `cfg = 1.0` 下工作。
`cfg = 1.0` 意味着**没有引导**，也就是**负面提示词完全失效**，
模型会拿你的提示词从头画一张。实测：4 步的成品在第 1 秒就和原页差了一大截
（差异值 45，正常是 3 上下），8 步反而更糟（75.7）——**步数越多跑得越远**。

⇒ **换回基础 fp16 权重**（`wan2.2_ti2v_5B_fp16.safetensors`），
cfg 用 5.0，步数用 10 步。既快又不跑形。

**② 整体色调和构图大致在，但细节慢慢漂。**

这是正常的画面漂移，不是 bug。钥匙是**看它对不对得上**，而且要**多取几帧**：

> ⚠️ **别只看第 0 帧。** 第 0 帧跟原页几乎一模一样，很容易误判成「没问题」。
> 取 **第 24 / 48 / 120 帧**，看差异是**一路爬升**（坏）还是**涨到某个值就平了**（好）。

实测一条 241 帧的片子：第 0/40/80/120/160/200/240 帧的差异分别是
1.7 / 5.3 / 5.4 / 5.2 / 5.3 / 5.4 / 5.5。**1.5 秒之后就不动了**，
剩下的只有树叶、水波、萤火虫这类微动。这就是好片子该有的曲线。

## 速度：一页要跑多久

一页 10.04 秒（241 帧）、10 步、1280×704，在 RTX 4080 上：

| | 数值 |
|---|---|
| 单页 | **约 8 分钟**（实测 423~520 秒，中位 428 秒） |
| 14 页一整本 | **约 108 分钟** |
| 显存峰值 | **12.3 GB**（最高见 14.4 GB） |

### 怎么变快

1. **砍步数，别碰蒸馏 LoRA。** 20 步和 10 步的画面**肉眼没有区别**
   （漂移 6.64 对 5.83），时间差一倍。10 步是甜点。
2. **别拆段。** 一页一段 10 秒，比「两段 5 秒拼起来」快，而且没有接缝。
3. ⛔ **别用闪电 LoRA。** 挂了蒸馏 LoRA 之后 `KSampler` 会直接崩：
   `HostBuffer.read_file_slice failed`。LoRA 文件本身是好的（1099 个张量），
   是 ComfyUI 动态显存与补丁器的冲突。合并版权重能跑，但见上一条，画会跑形。
   这条路已经走死，别浪费时间。
4. **先跑一页。** 界面上「只跑前几页」填 `1`，跑通看效果再放开。
   一页 8 分钟，试错代价不小。

## 显存

一页 10 秒 720p 峰值 12.3 GB，16GB 的卡塞得下，跑完不 OOM。
更小的卡可以调 `config.json`：

```json
"video": { "width": 704, "height": 480, "frames": 121, "steps": 10 }
```

代价是每页只有 5 秒，而且分辨率降下来水彩的笔触会糊。

## 连不上 ComfyUI / 返回 502

**十有八九是本机代理干的。**
系统里设了 `HTTP_PROXY` 的话，访问 `127.0.0.1` 会被代理拦下，回你一个 502，
看起来像「ComfyUI 没启动」。本项目所有请求都走一个**空代理的 opener**，
已经绕开了；如果还报 502，那才是 ComfyUI 真的不在。

排查顺序：

1. 浏览器打开 `http://127.0.0.1:8188`，出界面说明它在跑
2. 自检里 ComfyUI 那行是红的？看它给的原话
3. ComfyUI 装在别的机器 / 别的端口 → 改 `config.json` 的 `comfy_url`

## 音轨：片子在本机好好的，传上去旁白整体提前了

**这是最阴的一条，因为在本机所有播放器里都看不出来。**

起因是 `amix` 的行为：**它的输出从「第一路输入的起点」开始，晚开始的那几路
在这一刻之前的样本会被整段丢掉**（不是补静音）。

第一条旁白在 6.5 秒才出现，于是：

* 音频流的 `start_time` 被写成 **6.478667**，前 6.5 秒不落样本，
  靠 mp4 的**空编辑（elst）**表达
* 合规播放器照 elst 延迟出声，本机听是对的
* 但平台方重编码**一旦丢掉 elst**，旁白就整体提前 6.5 秒
* 顺带，配乐的前 6.5 秒被丢光，**封面镜头一点声音都没有**，
  那 0.8 秒音频淡入也落在空区，等于没做

**解法**：补一条 t=0 的静音流，并让它当 `amix` 的**第一路输入**。
本项目已经这么做了，硬指标是：

```
音轨起点  start_time=0.000000   ✅ 前段静音是实样本
```

**自己怎么验**：`python app.py --check` 之后跑第 4 步「出厂校验」，
它会直接把这行打出来。非 0 就是有问题。

> 另一个坑：**只解音轨时，ffmpeg 会把输出平移到 0，把 `start_time` 藏起来。**
> 所以「解出来听，旁白在第 0.45 秒就有了」这种读数会让人误判成「提前了 6.5 秒」。
> 校验脚本会按容器声明把前导静音补回来，再做取样。

## 字幕

### 一条都不显示，而且不报错

按这三条查：

1. **`-ss` 必须写在 `-i` 之后。** 写前面是输入侧定位，时间戳会归零，
   ASS 字幕全部错过，**而且一条错都不报**。
2. **滤镜里的路径要转义。** `subtitles='D\:/x/字幕.ass':fontsdir='C\:/Windows/Fonts'`
   —— 盘符那个冒号不转义，解析会在 `C:` 处断掉，报
   `No option name near '/Windows/Fonts'`。
3. **拿单张 PNG 试烧字幕时，`Dialogue` 必须从 `00:00:00.00` 起。**
   静态图只有第 0 帧，你写在 0.1 秒起，整帧就错过了，看起来像「样式没生效」。

### 字幕看不清

水彩画亮部多，**半透明深色描边压不住**。用接近纯黑的实色描边、宽度 4~5：

```
Style: Body,KaiTi,46,&H00FFFFFF,&H00FFFFFF,&H00120A04,&H90000000,0,0,0,0,100,100,1,0,1,4,3,2,80,80,48,134
```

测试的时候要在**亮度差得多的几页上都看一遍**（比如亮天的出走页、暗夜的独坐页），
只在一页上试会骗过自己。

### 整片比时间轴长一点点，字幕越来越晚

**时长要量化到整帧。** `-t 10.18` 会被 ffmpeg 推到下一帧（10.208），
十几段累积下来整片比时间轴长出 0.2 秒以上，字幕就整体偏晚。

⇒ 本项目用 `-frames:v round(秒 × fps)` 代替 `-t`，每段都落在整帧上。
实测成片 137.417 秒 = 3298 帧，和时间轴一模一样。

## 配乐

### 垫上去听不见

**别写固定倍率。** 素材本身的电平你不知道，同一个倍率可能低到没影：
实测某次生成的曲子 RMS 只有 **-27 dBFS**，乘 0.14 之后是 **-44 dBFS**，等于没放。

⇒ 本项目先把配乐 `loudnorm` 归一到 **-16 LUFS**，再整体压 **13 dB**。
这样垫底电平**跟素材无关**，换哪首曲子都一样。

判据：旁白 -19 dBFS RMS 左右，配乐垫到 -32 dBFS —— 句子间隙里听得见，
说话时听不出抢。校验里「片头 0~2 秒，每 0.25 秒 RMS」那一行是逐格递增的，
就说明淡入生效了。

### 配乐哪来

放个 mp3 就行。想**自己作曲**，可以在本机跑
[ACE-Step](https://github.com/ace-step/ACE-Step)（开放权重，MIT）。
它的输出电平是未知的，所以按上面说的归一化流程走，不要写死倍率。

> ⚠️ ACE-Step 和 ComfyUI **抢显存**，两个必须串着跑，不能同时开。

## 改东西要重跑多久

片段和合成分两步，这是故意的：

| 你改了什么 | 要重跑 |
|---|---|
| 正文、字幕、配乐、淡入淡出、镜头时长 | **只重跑第 3 步**，几分钟（纯 CPU） |
| 某几页的「怎么动」 | 只重出那几页的片段 |
| 页图本身 | 重出对应页的片段 |

第 1 步默认**跳过已有片段**，所以重跑不会白算。

---

## 没有 N 卡 / 不想装 ComfyUI

**合成那一步不需要显卡。** 只要你手上有片段（自己出的、别人给的、
或者用云端跑出来的），第 2 步之后全是 ffmpeg 的活，核显机器、笔记本都行。

把片段按 `clips/<页 id>.mp4` 放进工程目录就行。**也认 `clips/<页 id>_c1.mp4`
这种带段号的命名**，方便你把已有的素材直接丢进来。

---

## 工程目录可以就是绘本工坊那个吗

**可以，而且推荐。** 本项目读 `project.json` 与 `img/<页 id>.png`，
只**新增**自己的东西（`motion.json`、`voice/`、`clips/`、`build/`、`out/`），
**不覆盖、不修改绘本工坊的任何文件**。

首次运行时会从绘本里的正文自动生成一份 `motion.json` 初稿 ——
正文本身就是最好的旁白稿。

## 「怎么动」没人替我写吗

本项目**不接大模型**，所以这句得你来，或者把每页的分镜丢给任意一个 AI
让它照着写一句。写得越具体越好：

| | |
|---|---|
| ❌ 差 | 「小狐狸在走路」 |
| ✅ 好 | 「小狐狸走在铺满落叶的林间小路上，回头张望，大尾巴高高扬起，枫叶在风里一片片飘过，阳光透过树缝洒下晃动的光斑。」 |

两句都不到的功夫，但画面差别很大。留空的话会套一句通用的兜底描述，
画面会动，只是不贴故事。
