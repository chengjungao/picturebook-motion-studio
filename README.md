# 让绘本动起来

**用你自己电脑上的 AI，把一本做好的绘本，变成一集有旁白、有字幕的动画片。**

页图逐页动起来 → 配上旁白 → 排好时间轴 → 烧上字幕 → 一条能整集播放的片子。
全程在你自己的机器上跑，不联网、不排队、没有额度。

## 这个项目解决什么问题

让一张图动起来，现成的工具不少。难的是**把一叠图变成一集能看的片子**：

| 卡在哪 | 这里怎么处理 |
|---|---|
| 每页都只有 5 秒，凑一集得拼十几段，接缝处会跳 | **一页一段、整段 10 秒**。不拼接就没有接缝，画面也不累积漂移 |
| 镜头长短和旁白对不上，一响就错位 | 时间轴**算出来**：镜头 = 旁白时长 + 前后各 0.5 秒，再量化到整帧。不靠手感调 |
| 旁白只有 -25 dBFS，配乐一垫就听不见了 | 旁白先按 EBU R128 归一到 -16 LUFS，配乐再整体压低 13 dB，跟素材本身的电平无关 |
| 画面亮的地方字幕看不清 | 字幕描边用接近纯黑的实色、宽度 4~5，不吃「半透明深色描边」那一套 |
| 片子在本机好好的，传上去旁白整体提前了 6 秒 | 音轨**从 0 秒就有实样本**，不靠 mp4 的空编辑表达前导静音。`app.py --check` 里能量出来 |
| 改一句话就得重出全部片段 | 片段和合成是两步。改文字、改配乐只重跑合成，几分钟的事 |

## 先看能不能接受

| | 要求 |
|---|---|
| 显卡 | **N 卡**，显存 16GB 级别（本项目按 16GB 实测：峰值 12.3GB） |
| 磁盘 | **约 25 GB** 空闲（Wan 2.2 的权重 16.9 GB ＋ 中间片段） |
| 系统 | Windows / macOS / Linux 都行（双击入口是 Windows 的） |
| 其余 | Python 3.8 以上；**ffmpeg**（合成必需）；**ComfyUI**（出片段必需） |
| 时间 | 一页 10 秒的片段约 **8 分钟**。一本 14 页的书，出片段约 **1 小时 50 分** |

**本项目不包含** ComfyUI、模型权重和 ffmpeg，这三样要自己装好。
步骤见 **[docs/环境准备.md](docs/环境准备.md)**。

> 没有 N 卡也能玩一半：只要你手上有片段（或者别人给），
> 第 3 步之后都是纯 ffmpeg，核显机器照样出色。

## 怎么用

### 1. 先有一本绘本

这个项目**从页图开始**。页图可以来自：

* **绘本工坊**（[comfyui-picturebook](https://github.com/chengjungao/comfyui-picturebook)）——推荐，页图放在 `img/<页 id>.png`，本项目直接认这个目录
* 你自己手绘、或者别处生成的图，按 `img/01-xxx.png` 命名丢进去
* 示例工程里有一份写好的分镜和正文，缺的只是页图

### 2. 双击「启动.bat」

| 系统 | 怎么做 |
|---|---|
| **Windows** | 双击 `启动.bat`（也可以双击 `启动-自检.bat` 先体检） |
| **macOS / Linux** | 终端里 `./start.sh` 或 `python3 app.py` |

浏览器会自动打开界面。**关掉那个黑窗口，界面就停了。**

> **不需要 `pip install` 任何东西** —— 这个项目只用 Python 标准库。

### 3. 界面上四步走

```

  ① 出片段            ② 配旁白            ③ 合成成片          ④ 出厂校验
  每页 10 秒    →     收你的音频     →     排轴＋混音＋烧字幕 →  逐条量给你看

```

**① 出片段**　要 ComfyUI 开着、Wan 2.2 权重在位。第一次先填 `1` 在「只跑前几页」里，
跑通一页看看效果，再放开跑全部 —— 一页 8 分钟，试错的代价不小。

**② 配旁白**　把每页的音频丢进去就行。本项目**不替你念**，理由在下面。
如果你已经在机器上装好了 Kokoro-82M 的中文版，在 `config.json` 的 `tts` 一节
填上模型目录和解释器路径，界面上会多出一个「一键生成」。

**③ 合成成片**　片段有了之后这一步只吃 CPU，几分钟。配乐是可选件：
把 `配乐.mp3` 放在工程根目录，它会自动垫上。想自己作曲，见
[docs/常见问题.md](docs/常见问题.md) 里 ACE-Step 那一段。

**④ 出厂校验**　逐条量：容器时长、帧数、音轨起点是否为 0、每一条旁白
在字幕标称的位置上是不是真的有声，最后抽几帧出来确认字幕烧上去了。

## 时间轴这笔账

整片时长不是猜的，是加出来的。以示例那本 14 页的书为例：

| 镜头 | 个数 | 每个时长 | 怎么来的 |
|---|---|---|---|
| 封面 | 1 | 6.00 秒 | 固定值，只有标题和副题 |
| 内页 ＋ 封底 | 13 | 6.0 ~ 10.7 秒 | 旁白时长 ＋ 0.5 秒入 ＋ 0.5 秒出（不足 6 秒按 6 秒） |
| **合计** | **14** | **137.417 秒** | ＝ 3298 帧 @ 24fps |

片段固定 10.04 秒，所以镜头比它短就裁尾、比它长就冻结末帧补。冻结听着糙，
但实测画面在 **1.5 秒**左右就稳定下来了，之后只有树叶、水波、萤火虫这类微动，
补出来的部分肉眼看不出来。

## 下面这些事我不替你做

一个项目最要紧的是把边界说清楚：

* **不替你出页图。** 那是上一件事（绘本工坊），页图是这里唯一的输入。
* **不替你念旁白。** 内置语音合成要拖进 torch 这一串重依赖，
  把「解压就能用」变成「先装半小时环境」。念稿这件事，录音笔、系统朗读、
  手机上的朗读功能都能干。想全本地跑，接 Kokoro 就行，配置在 `config.json`。
* **不替你作曲。** 配乐放一个 mp3 进来即可；本机作曲是另一件事。
* **不含 ComfyUI 与模型权重。** 体积太大，也各有各的许可证，见 [NOTICE.md](NOTICE.md)。

## 目录结构

```
让绘本动起来/
├── 启动.bat              双击这个
├── app.py                入口（--check / --plan / --example）
├── config.json           所有可调项，首次运行自动生成
├── motion/               核心代码，只用标准库
│   ├── comfy.py          ComfyUI 客户端（上传页图、提交、轮询、取回）
│   ├── workflow.py       Wan 2.2 图生视频的节点图
│   ├── render.py         逐页出片段（断点续跑）
│   ├── timeline.py       时间轴推算 ＋ ASS 字幕
│   ├── assemble.py       整形、拼片、混音、烧字幕、淡入淡出
│   ├── verify.py         出厂校验
│   ├── media.py          ffmpeg / ffprobe 封装（踩过的坑都写在注释里）
│   └── web.py            本地界面服务
├── web/                  界面（原生 HTML/CSS/JS，没有构建步骤）
├── workflows/            工具提交给 ComfyUI 的那张图（API 格式，从代码导出）
├── examples/             示例工程：分镜、正文、运动描述
└── docs/                 环境准备、常见问题
```

**工程目录**（默认 `我的动画/`，或者你指向绘本工坊那个目录）：

```
我的动画/
├── project.json      ← 绘本工坊写的，本项目只读
├── img/              ← 绘本工坊出的页图，本项目只读
├── motion.json       ← 本项目写的：每页一句「怎么动」
├── voice/            旁白
├── clips/            片段（本项目出）
├── build/            中间产物：分段、字幕、无整片
└── out/              成片
```
